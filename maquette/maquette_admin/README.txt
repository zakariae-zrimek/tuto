MAQUETTE UI - CENTRE DE CONTROLE

Contenu du ZIP :
- maquette-complete.png : proposition UI complète et cohérente.
- reference-*.jpeg : captures de l'application actuelle fournies comme références.

Fonctions couvertes dans la maquette :
1. Tableau de bord / Centre de contrôle
2. Centres de services : liste, ajout, modification/suppression via actions
3. Rôles : liste et modal d'ajout
4. Modules : liste
5. Modules par centre de services : activation/désactivation
6. Matrice rôle/module : autorisations par rôle
7. Utilisateurs : rattachement à un ou plusieurs centres

Direction visuelle :
- Light mode enterprise / SaaS
- Sidebar fixe
- Header avec recherche et profil
- Cartes statistiques
- Tables structurées
- Badges d'état
- Modals cohérents
- Bleu comme couleur primaire

Cette archive est une maquette visuelle, pas encore le code Angular/CSS de production.
